
tools magnet designers need
==========================
* tools based on analytical equations to fast calculate the main parameters
* tools to do 2D design
* tools to do 3D design
* optimization tools
* visualization tool
* magnetic field analysis tools (or, magnetic field processing tools) -- such as one created by ESRF (magfieldtools https://gitlab.esrf.fr/IDM/magfield)


**Optimization tools**
(1) pole shape optimization
(2) senstivity analysis
(3) fast computation



Free tools available
===================

ESRF Insertion devices and magnets group     https://gitlab.esrf.fr/IDM

   (Radia, B2E, B2E-py, Magfield, SWLab, Undulatorradiation)

MAGNETIC FIELD TOOLS, A C++/PYTHON LIBRARY FOR MAGNETIC FIELD PROCESSING 
https://accelconf.web.cern.ch/ipac2023/pdf/WEPL126.pdf
  (https://gitlab.esrf.fr/IDM/magfield)


**Sirepo** provides browser access to physics codes like elegant, Warp, SRW, JSPEC, Zgoubi, and more.
  https://pypi.org/project/sirepo/
  The **rsradia** package contains utility functions and extensions for the Python version of the code Radia.
  https://github.com/radiasoft/rsradia


MAGNUM - A Fortran Library for the Calculation of Magnetic Configurations
  general formulae for the calculation of magnetic field generated by conductors in plane 2-D, axisymmetric 2-D and 3-D  configurations, in the presence of current and magnetization sources. All formulae have been programmed in numerically
stable routines, collected in a library named MAGNUM.
https://supermagnet.sourceforge.io/notes/CRYO-06-034.pdf
