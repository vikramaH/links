Q1 : You have created a good python program for analyzing PM planar undulator. In that you have used field calculations for 4 magnet Hallbach array.  What other magnet arrays are possible for which you can analytically calculate magnetic field?*

There are several other magnet arrays beyond the 4-magnet Halbach array for which analytical magnetic field calculations are possible. Here are the main types:

    Standard Planar Undulator (2-magnet array) - The simplest configuration with alternating north and south poles. Fields can be calculated using Fourier series expansions or the scalar potential approach.
    3-magnet Halbach array - A simpler version of the 4-magnet configuration that still provides field enhancement on one side but with lower efficiency.
    Pure permanent magnet (PPM) undulators - Uses blocks with alternating magnetization directions without pole pieces. The field can be calculated using the magnetic charge method.
    Hybrid undulators - Combines permanent magnets with ferromagnetic poles. Fields can be analytically approximated using methods like equivalent current distributions.
    APPLE-type undulators (Advanced Planar Polarized Light Emitter) - Consists of four quadrants of magnet arrays that can be shifted relative to each other. The analytical field expressions can be derived using superposition of individual quadrant contributions.
    Delta undulators - A type of helical undulator with analytical field expressions derivable from the magnetic scalar potential.
    Higher-order Halbach arrays (K>4) - More complex arrays with K=5, 6, or higher numbers of magnets per period, which can be solved analytically using harmonic expansions.
    Canted pole undulators - Modified planar undulators with analytical expressions derivable using the mirror charge method.

Q2. What information is needed to calculate magnetic field for the 2 magnet array?

To calculate the magnetic field for a 2-magnet array (standard planar undulator), you need the following information:

    Undulator period length (λu) - The distance over which the magnetic field pattern repeats
    Gap distance (g) - The separation between the upper and lower magnet arrays
    Magnet dimensions:
        Width of the magnets
        Height/thickness of the magnets
    Remnant magnetization (Br) of the permanent magnets (typically given in Tesla)
    Magnetization direction for each block (usually alternating in the vertical direction)
    Number of periods in the undulator

With this information, you can calculate the magnetic field using analytical expressions. For a standard planar undulator with infinite periodicity, the on-axis vertical magnetic field component can be approximated by:

B_y(z) = B_0 * sin(2π*z/λu)

Where B_0 is the peak magnetic field strength, which can be derived from:

B_0 = B_r * (1 - exp(-2πh/λu)) * exp(-πg/λu)

Where:

    B_r is the remnant field of the magnets
    h is the magnet height
    g is the gap distance
    λu is the undulator period

For a more accurate calculation that accounts for finite magnet width and the actual 3D geometry, you would need to use more complex analytical expressions that sum the contributions from each magnet face using the magnetic charge or current sheet equivalence methods.
